# Stage 2 prospective protocol — 2026-11-11

Stage 1 and its follow-up remain historical evaluations. All nine previously observed angles (0,15,30,45,60,90,120,150,180 degrees) now form the stage-2 development/fit set. Their old held-out labels do not make them new validation data.

Before computing new reference energies, fit equal-weight least-squares cosine series of orders 3 (baseline), 4 (primary extension), and 5 (secondary diagnostic), including a constant. Freeze all coefficients and predictions. Equal point weights overrepresent the previously targeted low-angle region; this is an explicit design choice, not uniform-angle fitting. No tuning after evaluation.

New fixed validation angles: 20,75,105,135,165 degrees. The 20-degree point checks the known low-angle discrepancy; the other four broaden coverage of previously sparse intervals. This is a designed five-point evaluation, not a random sample or a global error bound. Report per-angle errors, MAE, RMSE and maximum absolute error separately for each preregistered model. Do not select a winning model and claim an additional independent test using the same five points.

Run five constrained Gaussian optimizations with the same B3LYP/6-31+G(d),6D,Opt=(Tight,ModRedundant),SCF=Tight,Int=UltraFine,NoSymm,charge0/multiplicity1 and D1-5-8-11 freeze as before. Use the existing matched 180-degree energy as reference. Accept only normal termination, four convergence criteria YES, torsion error below 0.01 degree, retained bond graph and matched input/output hashes. No frequency calculation at constrained points.

For each model report interior stationary points and, only for the expected three-well topology, uniform-dphi basin integrals at 298 K (1000/10000 cells per half-domain basin). These are electronic curve approximations, not RRHO-corrected or experimental populations. Minimum location/gap are already-known diagnostics. Do not add extra degeneracy to mirrored integration. Stop after this five-job batch and record uncertainties.
