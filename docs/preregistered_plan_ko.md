# Fourier 후속 계산·검증 계획 — 2026-10-15

상태: 설계 완료. 이번 분석에서는 추가 Gaussian 계산과 Fourier fit을 실행하지 않았다.

## 계산 행렬

| 용도 | 각도 | 새 계산 수 |
|---|---|---:|
| 동일 설정 기준점 및 모형 결정 | 0°, 60°, 120°, 180° | 4 |
| 사전에 보류한 검증점 | 30°, 90°, 150° | 3 |

총 7개의 제약 최적화를 제안한다. 기존 네 점을 다시 계산하는 목적은 원본 복구가 아니라 새 최소점과 수치 조건을 맞추는 대조 실험이다. 특히 고정 60°와 실제 gauche 최소점을 같은 설정으로 비교해 각도 완화 효과를 분리한다.

모든 점은 B3LYP/6-31+G(d), 6D, Opt=(Tight,ModRedundant), SCF=Tight, Int=UltraFine, NoSymm, 중성 singlet으로 통일한다. D 1 5 8 11 F로 탄소 사슬의 이면각만 고정하고 다른 자유도는 최적화한다. 장벽점에 frequency 열화학을 적용하지 않는다. 전자에너지만 비교하고 같은 세트의 180°를 기준으로 삼는다.

## 계산 결과 채택 기준

- 정상 종료, 최적화 완료, 최종 수렴 네 항목 YES.
- 실제 좌표의 이면각과 목표각 차이가 0.01° 이내.
- C4H10 원자 구성과 연결 구조 유지.
- 입력 변환, 원본 출처, 해시, 최종 구조와 에너지의 대응 기록.

미수렴점은 누락으로 기록하고 보간값으로 채우지 않는다. 특정 시작점의 제약 최소가 전체 단면의 전역 최소임을 보장하지 않는다. 불연속이나 이상한 에너지가 보이면 추가 시작점 확인을 별도로 기록한다.

## 사전에 고정할 모델

주모형은 V(phi) = a0 + sum(n=1..3) an cos(n phi)이다. Butane의 거울대칭을 가정한 짝함수와 360° 주기성을 반영한다. 기준점 네 개로 계수 네 개가 결정되므로 기준점 잔차 0은 예측 성능의 증거가 아니다.

보조모형은 n=1..2의 최소제곱 모형이다. 두 모형을 미리 정하고, 보류점 결과를 본 뒤 차수를 선택해 같은 보류점을 독립 테스트로 다시 사용하지 않는다. 모델을 재조정하면 새로운 검증 각도가 필요하다.

## 평가

30°/90°/150°의 새 Gaussian 값을 정답으로 사용한다. 각 점의 오차, MAE, RMSE, 최대 절대오차를 모두 보고한다. 보간값·대칭 복제·동일 파일 사본은 독립 정답이 아니다. 세 점만으로 전체 곡선의 정확도나 신뢰구간을 주장하지 않는다.

이미 읽은 ±65.3156° 최소위치와 3.830641 kJ/mol gap은 추가 물리 진단으로 활용한다. 계획 수립 전에 관측한 값이므로 눈가린 독립 테스트로 표시하지 않는다. 대칭인 ±점도 독립 표본으로 세지 않는다.

## 1차원 분포

모형의 정지점으로 우물 경계를 정하고 uniform dphi 측도로 exp(-V/RT)를 적분할 수 있다. 수치 격자 세분화는 적분 알고리즘의 수렴이며 Gaussian 곡선 정확도의 검증이 아니다. 최소점 전자에너지 모형 및 RRHO 모형과 나란히 비교한다. 세 검증점만으로 적분 분포를 실제 정답이라고 주장하지 않는다.

곡선 오차나 모형 사이 분포 차이가 해석에 영향을 주면 다음 단계에서 15° 간격 등의 추가 각도를 정하고 실제 계산한다. 데이터가 늘기 전 ML 모형은 추가하지 않는다.

## 서버 실행 조건

기존 방식인 각 4코어·4GB, 최대 3개 동시 작업을 후보로 한다. 실행 직전에 가용 CPU·메모리·다른 사용자 작업·할당 제한을 다시 확인한다. 물 연구와 분리한 새 run 폴더를 사용하고 기존 입력·로그는 덮어쓰지 않는다.
